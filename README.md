# S S Manikanda Prabu — Full Stack Software Engineer Resume & Portfolio

Interactive, modern full-stack developer resume and portfolio web application built with Node.js, Express, Modern JavaScript (ES6+), and responsive glassmorphism CSS.

## 🚀 Live Demo
- Production URL: Deployed on Railway Cloud

## 🛠️ Tech Stack
- **Frontend**: Vanilla JavaScript (ES6+), HTML5, Modern CSS3 (Custom Properties, Flexbox, Grid), ATS-friendly `@media print` styling
- **Backend**: Node.js, Express, RESTful API endpoints, Health monitoring
- **Deployment**: Railway Cloud / Containerized deployment

## 🌟 Highlights
- **Flagship Project**: Pulpee Réserve Luxury E-Commerce Platform
- **Features**: Dark/Light executive theme toggle, interactive skills filter, one-click PDF print export, mobile-first responsive drawer navigation.

## 📦 Running Locally
```bash
git clone https://github.com/SSManikandaprabu/fullstack-resume.git
cd fullstack-resume
npm install
npm start
```
App runs at `http://localhost:3000`.
